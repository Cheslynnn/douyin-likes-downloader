# 抖音喜欢列表下载器

Windows 本地软件，用于从自己的抖音“喜欢”页面采集列表，并保存其中的视频和图文图片。项目包含可执行文件和对应源码。

## 使用

1. 下载 [`dist/DouyinLikes.exe`](dist/DouyinLikes.exe) 并双击运行。
2. 点击“打开抖音窗口”，在软件打开的专用浏览器窗口登录抖音，进入自己的主页并打开“喜欢”。首次使用可能需要重新登录。
3. 在软件中选择保存位置，点击“一键采集并下载”，保持抖音窗口打开。

软件尝试自动滚动加载喜欢列表。只有观察到从首页连续加载至末页时才继续自动下载；遇到登录验证、加载中断或网页改版时可能需要重试。也可以通过“导入已有清单”使用之前采集的 JSON 清单。

视频保存在“视频”文件夹，图文图片转换为 JPG 后保存在“图片”文件夹，多张图片使用文案和序号命名；同名作品会增加区分编号。保存位置还会生成下载报告。图片采用作品详情返回的地址，不能保证网站将来总是返回无水印图片。

## 环境与隐私

- Windows 桌面环境，电脑需安装 Chrome 或 Microsoft Edge。无需另外安装 Node.js。
- 程序使用独立的浏览器资料保存登录状态；登录资料保存在本机，不包含在本仓库中。
- 喜欢列表由已登录网页加载；程序会在该页面请求图文作品详情以获取图片地址，媒体文件由本机下载。请勿上传浏览器资料、下载结果或个人清单。
- 自动化使用本机浏览器调试连接。使用完毕后可关闭程序打开的专用浏览器窗口。

## 验证范围

软件启动、本机浏览器连接、JPG 转换、模拟多图采集及保存规则已作测试。合并后的自动采集到下载流程尚未用真实抖音账号完成端到端验证。抖音的页面、登录验证和接口可能发生变化；建议先少量测试，并检查下载报告。

## 从源码构建

Windows 自带 .NET Framework 4.x 编译器的环境下，双击 `build.cmd`，生成文件位于 `build\DouyinLikes.exe`。源码位于 `src`，其中 `unified-collector.js` 会被嵌入程序。
